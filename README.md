## Descripción del proyecto
Este proyecto es un trabajo grupal para la materia de Base de Datos, presentado como un sistema de gestión para una cava de vinos.

El objetivo principal es diseñar un modelo entidad-relación y analizar los requisitos funcionales y no funcionales necesarios para una base de datos que permita:
- Centralizar la información de vinos, proveedores, clientes, compras y ventas.
- Gestionar inventario con ubicación precisa dentro de la cava.
- Registrar evaluaciones de sommeliers.
- Generar recomendaciones de maridaje.
- Mantener trazabilidad en compras y ventas.

## Archivo principal
- `cava_vinos_presentacion_GRUPO3.html`: presentación del proyecto con la descripción del negocio, problemáticas, objetivos, requisitos y diagrama.

## Tecnologías y herramientas
- HTML
- CSS
- Diseño de modelo entidad-relación (Draw.io)

## Propósito
El sistema busca resolver problemas de control de inventario, registro de compras y ventas, gestión de evaluaciones de vinos y respaldo de recomendaciones de maridaje, usando un enfoque de base de datos relacional.
